# Pareto Analysis

Status: Approved
Date: 2026-05
Branch: main

## Context

The Pareto curves experiment evaluates explanation quality as a function of explanation size. This design addresses a known limitation of raw fidelity comparisons: methods can appear strong when they preserve large portions of the graph, while smaller explanations are penalized for removing more context. A fair comparison therefore requires matched edge budgets.

The experiment measures three quantities across explanation sizes. Sufficiency is defined as `1.0 - fidelity_minus`, so higher values indicate that the explanation alone preserves the model prediction. Necessity is defined as binary `fidelity_plus`, so higher values indicate that removing the explanation changes the prediction. Sparsity is the fraction of local neighborhood edges removed.

The main comparison uses `frac=0.05`, which corresponds to the smallest tested explanation size. At this budget, the Cora results show that Ours reaches necessity `0.36`, while Random reaches `0.06`, giving a 6x advantage at matched budget. On Citeseer, Ours reaches necessity `0.70`, the strongest necessity score among the compared methods at the matched budget. On PubMed, the results are limited by a sparsity issue: the 2-hop reference neighborhood covers nearly the full graph, and Ours records sparsity `0.002` at `frac=0.05`, so the resulting explanation is not a compact local explanation.

## Decision

The project will use the Pareto curves experiment as the primary evidence for matched-budget explanation quality. Raw binary fidelity remains useful for diagnosing behavior at default explanation sizes, but the accepted comparison for explanation quality is the Pareto setting, where methods are evaluated at the same size fraction relative to a local k-hop reference.

The approved experiment compares Ours against Random, Degree, and KHop baselines. Ours is generated by `CoarsenExplainer` with `k=100` and `alpha=0.75`, then pruned by edge weight to the target edge count. Random and Degree receive the same `k_frac` as the tested size fraction. KHop uses a fixed 2-hop subgraph and therefore does not shrink across the tested fractions.

### Experiment Parameters

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Datasets | Cora, Citeseer, PubMed | Standard citation graph benchmarks used in the project |
| Size fractions | 0.05, 0.10, 0.20, 0.30, 0.50 | Pareto sweep from compact explanations to larger explanations |
| Primary reported fraction | 0.05 | Smallest matched budget and clearest stress test for compact explanations |
| Methods | Ours, Random, Degree, KHop | Coarsening method compared with size-matched and neighborhood baselines |
| Sample count | 50 test edges | Default run size used in the reported Pareto result files |
| Seed | 42 | Deterministic sampling of test edges |
| Model checkpoint | `checkpoints/{dataset}_gcn.pt` | Uses the trained GCN link prediction checkpoint for each dataset |
| Ours explainer settings | `k=100`, `alpha=0.75` | Coarsening configuration used by `run_pareto.py` |
| KHop reference | 2-hop subgraph | Defines the reference edge count for pruning Ours and matching budgets |
| Metrics | Sufficiency, necessity, sparsity, mean edge count, sample count | Captures prediction preservation, causal importance, compactness, and run coverage |

### Code Reference

The experiment entry point is `experiments/run_pareto.py`. The script defines `SIZE_FRACTIONS`, loads the dataset and trained GCN checkpoint, samples positive test edges, runs each selected explainer, computes metrics, writes `results/pareto_{dataset}.json`, and saves `figures/pareto_{dataset}.pdf` when plotting succeeds.

Metric definitions and summary interpretation are recorded in `results/METRICS_README.md`. Dataset-specific numeric outputs are recorded in `results/pareto_Cora.md`, `results/pareto_Citeseer.md`, and `results/pareto_PubMed.md`.

## Consequences

This decision makes matched-budget Pareto analysis the preferred interpretation for the coarsening explanation results. It supports the claim that Ours identifies more necessary compact explanations on Cora and Citeseer than Random and Degree at `frac=0.05`, with Cora showing a 6x necessity advantage over Random and Citeseer showing the strongest necessity score among the compared methods.

The decision also narrows how PubMed should be discussed. PubMed should not be presented as evidence for compact coarsened explanations at `frac=0.05`, because the k-hop reference covers almost the full graph and Ours has sparsity `0.002`. PubMed remains useful as a diagnostic case showing that local neighborhood definitions can fail to impose a meaningful compactness constraint on dense or broadly connected regions.

Future analysis should keep raw fidelity, Pareto necessity, Pareto sufficiency, and sparsity separate. Raw fidelity reports default-size behavior. Pareto necessity reports whether a size-controlled explanation is causally important. Pareto sufficiency reports whether the explanation alone preserves the prediction. Sparsity confirms whether the comparison is truly compact.
